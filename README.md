# Aprendizaje Automático

Repositorio donde se almacenan prácticas y proyectos desarrollados durante el curso de Aprendizaje Automático utilizando Python y diferentes técnicas de Machine Learning.

## Contenido del repositorio

- Regresión Lineal
- Regresión Logística
- Clasificación Binaria
- Predicción de precios de automóviles
- Comparación de modelos de Machine Learning

## Herramientas utilizadas

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-Learn
- Google Colab

## Objetivo

Aplicar modelos de aprendizaje automático para resolver problemas de regresión y clasificación mediante el análisis y procesamiento de diferentes bases de datos.

## Estructura del proyecto

Cada notebook incluye:

- Análisis exploratorio de datos
- Limpieza y preprocesamiento
- Entrenamiento de modelos
- Evaluación de métricas
- Visualización de resultados
- Interpretación de resultados
